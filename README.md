# CediChat — website preview

Static landing page prepared for GitHub Pages and the planned custom domain `cedichat.site`.

## Preview
Open `index.html` in a browser, or use a local static web server. The profile photos load from an external portrait-image service and require internet access. All profiles are **illustrative**, not verified members.

## Publish only after approval
1. Create a public GitHub repository named `cedichat`.
2. Upload the contents of this folder to the repository root.
3. In GitHub repository Settings → Pages, deploy from the main branch root.
4. Purchase `cedichat.site`, configure GoDaddy DNS for GitHub Pages, and confirm the custom domain in GitHub Pages.
5. Enable HTTPS after DNS validation.
6. Verify all external links, photo licensing and display, SEO metadata, mobile appearance, and legal wording.
7. Connect and verify Google Search Console, then submit `https://cedichat.site/sitemap.xml`. Search Console verification requires an account-specific verification token that has **not** been added.
